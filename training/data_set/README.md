# 钢球检测数据集

本目录包含本项目训练 YOLOv8n 钢球检测模型所使用的数据集，采用 YOLO 目标检测格式，仅包含 `ball` 一个类别。

## 目录结构

```text
data_set/
├─ data.yaml
├─ images/
│  ├─ train/          # 347 张训练图像
│  └─ val/            # 57 张验证图像
└─ labels/
   ├─ train/          # 347 个训练标签
   └─ val/            # 57 个验证标签
```

图片与标签文件必须同名。例如：

```text
images/train/frame_0001.jpg
labels/train/frame_0001.txt
```

## 数据集统计

| 划分 | 图片 | 标签文件 | 目标框 | 图片尺寸分布 |
| --- | ---: | ---: | ---: | --- |
| 训练集 | 347 | 347 | 438 | 95 张 `320×30`；252 张 `640×60` |
| 验证集 | 57 | 57 | 87 | 29 张 `320×30`；28 张 `640×60` |

共包含 404 张图像、404 个配对标签和 525 个目标框。当前图像与标签均按文件名一一对应，标注类别均为 `0`。

## 数据配置

仓库中的 `data.yaml` 内容如下，相关训练命令均从仓库根目录执行：

```yaml
path: ./training/data_set
train: images/train
val: images/val

names:
  0: ball
```

本项目只包含一个检测类别：`ball`，类别编号为 `0`。如果移动数据集目录，请同步修改 `path`。

## 标签格式

每个目标占一行，采用 YOLO 归一化格式：

```text
class_id center_x center_y width height
```

示例：

```text
0 0.512500 0.483333 0.043750 0.366667
```

## 图像尺寸

原始检测区域为 `640×60`，也可以将其等比例缩放为 `320×30`。训练时使用 `rect=True`，有效图像上下各填充 1 行后，实际模型输入为 `320×32`。
